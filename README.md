## Compartilhamento e comunidade

Meu foco é documentar o raciocínio: que dados faltam, quais explicações benignas existem e como validar uma hipótese. Sugestões de documentação, testes e falsos positivos são bem-vindas. Contribuições externas serão vinculadas aqui quando efetivamente enviadas; não há participação ou aceite de terceiros alegados antecipadamente.

Os materiais não contêm logs internos, credenciais ou documentos de empregadores. Exemplos publicados com apoio de IA trazem o estado de validação correspondente.
